docs: the stealth address protocol, read, and the one obstruction it leaves

ePrint 2025/112 section 5.3, p. 16. The Module-LWE SAP solves the derivation problem my
earlier proposal got wrong.

The recipient registers two Kyber keys, spend K = (tK, rhoK) and view V = (tV, rhoV). The
sender encapsulates to the VIEW key to get (R, S), then computes

    P = XOF(rhoK)*XOF(S) + Decompress(tK, dt)

and the recipient derives p = k + XOF(S), with A*p + e1 = P. The sender knows S and can
compute P, but cannot compute p because it does not know k. That is precisely the
property the public-shift version lacked: the shift is XOF(S), a KEM shared secret, not a
public scalar.

THE OBSTRUCTION IS AT THE NORM. The tag is A'*s and the proof needs ||s||inf <= 5. The
stealth secret is p = k + XOF(S), where k is Kyber's short CBD secret but XOF(S) is a hash
output -- uniform mod q as written. A uniform p is a fine MLWE secret for a KEM, but SMILE
cannot prove knowledge of it as a short lattice vector. The paper does not state that
XOF(S) is short. If it were sampled from a short distribution, the construction would drop
into SMILE almost unchanged; if not, using it means giving up the short-secret proof for
stealth outputs, which is a different signature scheme rather than a modification.

That is now the single question on one-time addressing, and it is a question about the
paper's security proof as much as its text, so it goes to C1 and C2 together.

Derivation solved, compatibility open. That is a much better position than a week ago,
when the construction did not work at all.
