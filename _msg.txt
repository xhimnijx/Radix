fix: cryptographic randomness where it was Mersenne Twister, and a KDF for the seed

Two of the review's findings are the kind that are cheap to fix and expensive to leave: they do
not break a demo, they quietly weaken every wallet.

1. KEYS AND PROOF MASKS CAME FROM MT19937. wallet._rng_for returned random.Random, and the default
   proof-mask generator was `random.Random()`. Mersenne Twister recovers its entire state from 624
   consecutive outputs and makes no unpredictability claim, so it is the wrong primitive for key
   material -- and a predictable zero-knowledge mask reveals the secret it was meant to hide.

   Added radix_core/candidate_b/lattice/csprng.py: SHAKE256 in counter mode, rekeyed per block,
   providing exactly the four methods the samplers use -- randrange, randint, getrandbits,
   random -- with `random.Random`'s argument conventions so it drops in. randrange uses rejection
   sampling, so the distribution is exact rather than modulo-biased. Deliberately not a Random
   subclass, so nothing can depend on behaviour it does not promise.

   The wallet still derives deterministically from the mnemonic (that is the requirement), but the
   stream is now cryptographic: account index -> SHA3-256 -> keyed SHAKE stream.

2. THE MNEMONIC SEED WAS A BARE SHA-256. No work factor, so a stolen phrase file could be
   brute-forced at hash speed. Now PBKDF2-HMAC-SHA256 with the derivation version as salt and
   600,000 iterations -- measured at ~270 ms to unlock, imperceptible for a wallet and expensive
   per guess. The phrase -> seed property is unchanged, so recovery still works; the derived keys
   change, which is a wallet-format change and is stated here because it invalidates any address
   recorded before this commit.

Eight CSPRNG tests, and 64 tests across the wallet, wallet-seed, real-wallet-flow, scan-containment
and genesis suites pass.

Neither of these touches the defect that matters -- value is still not bound to notes -- but they
are the difference between a wallet that is merely unfinished and one that is unsafe to use.
