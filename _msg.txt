Two corrections found by the tests rather than by reading:

claims. Two-bit chunks make it a binomial of width 2, which is what CBD eta = 2 means.

key (the proof's own sample, width 5) plus a width-2 shift reaches 7, not the proof's mu of
5. With a Kyber CBD spend key of width 2 it reaches 4 and fits. That is exactly C2's
parameter point, now asserted as what it is instead of quietly loosened: which spend-key
distribution a wallet uses is a parameter decision, not an implementation detail.
